# ערכת עבודה: הוספת ספרים מוויקיטקסט לספריית אוצריא (המשך לשרשור הפורום 1468)

מסמך זה, והקבצים לצידו, נכתבו עבור **סוכן Claude עתידי שירוץ על מחשב *לא מסונן* (בלי נטפרי) ובלי גישה להיסטוריית השיחה שבה
נוצרה הערכה**. הערכה עצמאית: כל הקוד הנדרש נמצא בה, וכל מה שנלמד בעבודה הקודמת כתוב בה. קרא את הקובץ הזה עד הסוף ואז את
[PROCESS.md](PROCESS.md) - ורק אז הרץ משהו.

## המשימה בקצרה

המשתמש ביקש להוסיף לספריית אוצריא ספרים מוויקיטקסט העברי לפי [שרשור פורום אוצריא 1468](https://otzaria.org/forum/topic/1468)
(7 הודעות, 23 פריטים; הטבלה המלאה ב-[FORUM_THREAD.md](FORUM_THREAD.md)). בשיחה הקודמת הוספנו 9 ספרים (הקומיט `cf7abed08`, במקור
`17913135b`) ובדקנו את השאר. **12 פריטים לא הושלמו כי הורדת דפים מוויקיטקסט נחסמה בנטפרי (HTTP 418)** בסביבה ההיא. המשימה שלך:
להשלים אותם. הרשימה המפורטת - ב-[BLOCKED_BOOKS.md](BLOCKED_BOOKS.md).

## כללי ברזל (ממה שהמשתמש ביקש, ומה שנלמד)

1. **אין עקיפת חסימות.** הכלי מזהה חסימה (קוד שאינו 200, תגובה שאינה JSON, כותרות נטפרי, הפניה מחוץ לאתר, שגיאת SSL) וקורא לה
   "נחסם בנטפרי". במחשב לא מסונן הדפים אמורים להיות נגישים. **אם בכל זאת נחסמת - עצור על אותו דף ודווח.** אין פרוקסי, אין מראות,
   אין ארכיונים/קאש, אין גרסאות אחרות של אותו דף, ואין שימוש בתוכן חלקי מדף חסום. (429 = "לאט יותר", לא חסימה - חכה והרץ עם `--delay 2`-`3`.)
2. **לא להמציא.** מחבר, שנים, דור, תאריך דפוס, תיאור - רק ממה שכתוב בדף הספר/דף המחבר/מקור שאפשר לצטט. מה שלא ידוע נשאר ריק. (ידוע:
   בשיחה הקודמת התברר שהשנים ב-`book_info.csv` של "ספר הבחור" - 1038-1492 - כנראה שגויות; "ספר הרכבה" נרשם 1469-1549 ללא אימות. אל תכפיל טעויות.)
3. **שורת זכויות יוצרים בשורה 3 של כל קובץ בסיס** (הכלי מוסיף אוטומטית; ראה [PROCESS.md](PROCESS.md) צעד 5 ו-LESSONS).
4. **הספר חייב להיות שלם ככל שאפשר, אבל חלקי מותר.** המשתמש הורה במפורש להכניס גם ספרים שהם חלקיים בוויקיטקסט (למשל "תולדות
   תנאים ואמוראים"). אבל **ספר שחלק מדפיו נחסמו אצלך (418) - לא נכנס** (זה שונה: חלקי בוויקיטקסט הוא תוכן; חסימה היא כשל טכני). סמן "חלקי"
   בתיאור הקצר ובדוח.
5. **אל תמחק/תחליף קובץ של מקור אחר (דיקטה וכו') בלי אישור המשתמש.** מקרים כאלה (רוקח על שיר השירים, טור ברקת) - להציג למשתמש
   את ההשוואה ולחכות להחלטה.
6. **הכל בקומיט אחד** (ספרים + הערות + links + `manual_links_sync.json`/`manual_links_lineage.json` אם השתנו + שלושת המרשמים). `git commit --only -- <נתיבים>`
   כדי לא ללכוד קבצים מבוימים של אחרים. אל תיגע בקבצים לא-מעקוב של אחרים (בזמן הכתיבה היו כאלה ב-`ToratEmetToOtzaria/` ובשורש).
7. **שיחה נקייה והפרדה:** המשתמש מעדיף שכל עבודה כבדה (ספר אחד) תיעשה בסוכן/תהליך נפרד, ושהמפקח לא מבצע בעצמו.
   אם אתה סוכן יחיד - עבוד ספר-ספר, ובכל ספר סיים (קומיט) לפני הבא.

## התקנה מהירה (פירוט ב-[TOOLS.md](TOOLS.md))

דרישה קשיחה: **Python 3.12+**. מומלץ venv מחוץ לריפו (כדי לא ללכוד קבצים בקומיט).

```bash
# לינוקס / macOS
curl -LsSf https://astral.sh/uv/install.sh | sh
uv python install 3.12
uv venv --python 3.12 ~/venvs/ws && source ~/venvs/ws/bin/activate
uv pip install -r wikisourceToOtzaria/סקריפטים/wikisource_adding_guide/scripts/requirements.txt
```
```powershell
# Windows (PowerShell)
irm https://astral.sh/uv/install.ps1 | iex
uv python install 3.12
uv venv --python 3.12 $HOME\venvs\ws ; & $HOME\venvs\ws\Scripts\Activate.ps1
uv pip install -r wikisourceToOtzaria\סקריפטים\wikisource_adding_guide\scripts\requirements.txt
```

בדיקת תקינות (מתיקיית שורש הריפו; כותב רק לתיקיית פלט זמנית):

```bash
python -X utf8 wikisourceToOtzaria/סקריפטים/wikisource_adding_guide/scripts/ws_book.py \
  --page 'ספר זכרון (ריק"ם)' --out /tmp/ws_smoke --plan-only --delay 0.5
# צפוי: "סטטוס: תוכנית בלבד"; בדוח "נמצאו 14 תתי-דפים", 13 בתוכנית (פתיחה, שער א-שער יא, נספחים) ו"שלם" מדולג.
# אם יצא "נחסם בנטפרי" - ראה כלל 1.
```

הכלי מוצא את חבילת `mediawikitootzaria` של הריפו לבד (הוא יושב בתוך `wikisourceToOtzaria/סקריפטים/`); אין צורך ב-`--lib-dir`.

## קבצים שאינם נארזים - ודאנו שהערכה לא משפיעה על הספרייה או על CI

התיקייה `wikisourceToOtzaria/סקריפטים/wikisource_adding_guide/` **אינה נארזת**: `BOOK_ROOTS` ב-`manual_links_packaging.py` כולל רק
`wikisourceToOtzaria/ספרים/אוצריא`, ו-`PACKAGED_PREFIXES` ב-`validate_fordb_book_names.py` זהה; `links_roots` מצביע על `wikisourceToOtzaria/links`.
בקבצי הערכה אין `test_*.py`, ואף workflow אינו אוסף אותה (`python-tests.yml` מריץ `unittest discover` רק בשורש - בלי `__init__.py` הוא לא יורד
לתיקיות - ו-`unittest` מפורשים ב-`wikisourceToOtzaria/סקריפטים` על `test_mediawikitootzaria` בלבד; ה-sparse-checkout שלו אינו כולל את הערכה).
אל תוסיף לערכה קבצי `test_*.py`, קבצי ארכיון (`.zip`, `.tar.*`, `.gz` - הם LFS לפי `.gitattributes`), או קבצי נתונים גדולים.
