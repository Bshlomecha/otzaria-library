# ילקוט מדרשים — צינור הפיצול

שני כרכי "ילקוט מדרשים" (חלק ראשון, חלק שני) הגיעו כקובצי אוצריא עם הערות
משובצות (`<sup class="footnote-marker">` + `<i class="footnote">`). הצינור מפצל
אותם לספר לכל מדרש, לפי הערות העריכה שצורפו לקבצים.

התיקייה הזו **אינה נארזת**.

## הרצה

```bash
python3 build.py /tmp/out     # קלט: SRC ב־common.py (~/Downloads/ילקוט מדרשים - אוצריא)
python3 qa.py /tmp/out        # שחזור כל שורת מקור מהספר + הספר הנלווה + הקישורים
```

## מה הצינור עושה

- **ספר לכל מדרש** (`SPEC` ב־build.py): ה־`<h2>` של המדרש הופך ל־`<h1>` של הספר.
  שמות הקבצים מקבלים את הסיומת ` (ילקוט מדרשים)`, כי חלק מהשמות כבר קיימים במאגר
  וב־DB.
- **דף השער והפתיחה** של שני הכרכים לא נכללים. "שם הספר וזמנו" (חלק א) נכנס כמבוא
  למדרש חופת אליהו, ו"ליקוטים והוספות למדרש חופת אליהו" נכנס לסופו.
  "הקדמה קצרה למהדורה שנייה" (חלק ב) נכנסת לתחילת מדרש תדשא.
- **ההוספות** מתוך "השלמות והוספות" (חלק ב) נכנסות כל אחת לסוף המדרש שלה.
- **כותרת עם כינוי שני** ("X <small>או Y</small>") מפוצלת: הכותרת היא X, ו־Y יורד
  לשורה נפרדת (שורה 2 בספר).
- **כל סדרת הערות היא ספר נלווה נפרד**, כלומר מפרש נפרד בחלונית המפרשים:
  `הערות במספרים על X`, `הערות באותיות על X`, `שינויי נוסחאות על X` (הכוכבית של
  חלק א). הם מקושרים ב־`footnotes`. השמות **לא** מתחילים ב־`הערות על `, **במכוון**:
  אחרת `HearotCompanionMerge` היה ממזג אותם חזרה לפופאפ אחד.
  בחלק ב, הסמנים `*` ו־`ה*` הם תוספות בתוך סדרת האותיות.
- **מבוא מדרש תדשא** (הסבר הסימנים והקיצורים) מועבר לראש `הערות במספרים על מדרש תדשא`,
  ומקושר לשורה 2 של הספר.
- **ספר אורחות חיים**: סדרת האותיות, שהתחילה מחדש כמעט בכל פסקה, ממוספרת מחדש
  ברצף אחד לכל המדרש.
- **זכויות יוצרים**: שורה 3 בכל ספר, בסיס ונלווה, היא
  `© כל הזכויות שמורות למכון ׳אור עולם׳ - צפת.` בצורה של קומיט 260d2c1a.
  שורה 2 היא הכינוי השני או שורה ריקה.

## חלק ג (`build_g.py`, `qa_g.py`)

חלק ג הגיע כקובצי `.doc`, קובץ לכל מדרש, עם הערות שוליים של Word. הטקסט וסמני ההערות
נקראים מה־.doc הבינארי (olefile), כי textutil מאבד את הסמנים. העיצוב (מודגש,
`<small>` להפניות, מירכוז) נלקח מה־HTML של textutil ומיושר תו מול תו.

```bash
python3 build_g.py "~/Downloads/ילקוט מדרשים ג" /tmp/out
python3 qa_g.py   "~/Downloads/ילקוט מדרשים ג" /tmp/out   # כל אות, הערה וקישור
```

- **ספר לכל מדרש** (`BOOKS` ב־build_g.py), בתיקייה `חלק ג`. כל ההערות הן סדרה
  אחת, `הערות במספרים על X`, ממוספרת 1..N לכל ספר.
- **ההוספות ונוסחים נוספים** נכנסים כ־`<h2>` בסוף המדרש שלהם: אל יתהלל (נוסח ב +
  הוספה), כסא שלמה (סודי רזיא + התרגומים לאסתר), אגדות מספר המעשים (+ ההמשך + הקדמת
  הלכות גדולות).
- **מילת פתיחה** בפסקה נפרדת (drop-cap) מוצמדת לפסקה שאחריה. **מילת העמוד הבא**
  (קטשווורד אחרי שבירת שורה רכה) בתרגומים לאסתר נמחקת.
- **לא נכנסו:** "קטע גניזה" (שני הקבצים) ו"ברייתא דמסכת נדה".
- **"הוספות למדרש חופת אליהו"** אינו ספר נפרד: רובו כבר בסוף מדרש חופת אליהו בחלק א
  (משורה 893), בנוסח המאוחד של המו"ל. `patch_hupa.py` (חד־פעמי, נעצר אם כבר רץ) משלים
  שם את מה שחסר: הפתח דבר (הערה 1), סמן הערה 76 בסוף [מ], והסעיפים שהועתקו "כאן שנית"
  עם הערותיהם ([ג], [ט] אחרי [נד]; [כג]-[כז] אחרי [יט]). ההערות של הקטע ממוספרות לפי
  חלק ג (1-135), והקישורים של הקטע נבנים מחדש. הערות שהיו בחלק א נשארות בנוסחן שם,
  בלי הפניות לעמודי הדפוס שחלק ג מוסיף (הערות 3, 4, 6, 11, 17, 29, 54, 126).

```
python3 patch_hupa.py "~/Downloads/ילקוט מדרשים ג" ../../..
```
