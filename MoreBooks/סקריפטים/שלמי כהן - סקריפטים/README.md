# שלמי כהן — ציוני סוגיות על הש"ס (שלמה כהנוב)

15 מסכתות של "שלמי כהן", ציונים ומראי מקומות על כל דף ודף, מאת שלמה כהנוב
(נכתב לחבורת הדף בישיבת מיר ירושלים). כל מסכת היא ספר + ספר "הערות על" + קובץ קישורים:

```
MoreBooks/ספרים/אוצריא/תלמוד בבלי/מראי מקומות/שלמי כהן/
    שלמי כהן <מסכת>.txt
    הערות על שלמי כהן <מסכת>.txt
MoreBooks/links/שלמי כהן <מסכת>_links.json      "Conection Type": "footnotes"
```

התיקייה הזו **אינה נארזת** לשחרור. המקורות עצמם — ב־`extraBooks/שלמי כהן/`.

## המקור (`extraBooks/שלמי כהן/`)

| מה | איפה |
| --- | --- |
| קובצי ה־Word של המחבר, 90 קבצים, כפי שהתקבלו (כולל שמות עם `__` ועותק כפול) | `שלמי כהן וורד/<מסכת>/*.docx` |
| בכורות — אין לו docx; הקובץ שהומר מראש (ספר, הערות, links) | `מראי מקומות שלמי כהן/שלמי כהן בכורות/`, `שלמי כהן קישורים/` |

שאר הקבצים שהומרו מראש (14 המסכתות האחרות) **לא נשמרו**: הם נבנו מאותם docx, והבנייה
מחדש כאן משחזרת את כל הטקסט שלהם (ר' "מה תוקן").

## הרצה

```bash
cd "MoreBooks/סקריפטים/שלמי כהן - סקריפטים"
python3 -I convert.py --src ../../../extraBooks/שלמי\ כהן --out /tmp/shlomei        # --src חובה
python3 -I verify_conversion.py --src ../../../extraBooks/שלמי\ כהן --out /tmp/shlomei
python3 -I verify_merge_gate.py --root /tmp/shlomei                                  # בדיקה על ספרים שכבר הותקנו: --root ../..
python3 install.py --src /tmp/shlomei            # הרצה יבשה; --apply כותב לריפו ולמרשמים
```

| סקריפט | תפקיד |
| --- | --- |
| `convert.py` | docx → ספר + הערות + links. קורא סגנונות לפי *שם* (מזהי הסגנון משתנים בין הקבצים), מאחה קבצי־חלק חופפים, מספר הערות |
| `verify_conversion.py` | שימור: multiset של כל מילה במקור מול הפלט, בגוף ובהערות, לכל מסכת |
| `verify_merge_gate.py` | פורט של חוזה המיזוג של SeforimLibrary (`buildHearotMergePlans` + `mergeLines`): כל הערה נשתלת במקום הסמן שלה |
| `install.py` | מעתיק ספרים ו־links, ורושם ב־`metadata.json`, `ForDB/all_metadata.json`, `ForDB/book_info.csv`, `ForDB/sefaria_metadata_changes.csv` |

## המבנה

| שורה | תוכן |
| --- | --- |
| 1 | `<h1>שלמי כהן <מסכת></h1>` |
| 2 | `שלמה כהנוב` |
| 3 | `בס"ד` |
| אחר כך | `<h2>` פרק · `<h3>` דף · `<h4>` נושא (ישירות תחת הפרק כשעוד לא נפתחה בו כותרת דף: `<h3>`) |

- פסקה קטנה במקור (10pt, בסגנון "קטן"/"צ" או ריצה עם `sz=20`) — `<small>`; פסקה רגילה — בלי תג.
  `<small>` לא חוצה סמן הערה: `<small>…</small><sup>N</sup><small>…</small>`.
- **ההערות הן הערות שוליים אמיתיות של Word**, ממוספרות ברצף לאורך המסכת. כל הערה = שורה בספר ההערות
  (`<sup>N</sup> גוף`), פסקאות בתוך הערה מופרדות ב־`<br>`, נטייה — `<em>` (`<i>` בהערה פוסל את המיזוג).
  ב־DB ההערות נשתלות במקום הסמן ושורת ההערות נעלמת כספר (ר' `ADDING_BOOKS.md` סעיפים 2–4).
- סמן הערה שהיה בכותרת (פסחים 3 · בבא מציעא 1 · גיטין 1 · בבא בתרא 1, בקובץ שהתקבל) עבר לתחילת הפסקה
  שאחרי הכותרת: קישור לשורת כותרת אסור, והכותרת צריכה להישאר נקייה בתוכן העניינים.
- כותרת דף פותחת תמיד *תחת* הפרק: כשהקובץ מקדים כותרת דף לכותרת פרק שאחריה מיד (העמוד הראשון של
  הפרק), הסדר מתחלף. כותרת דף שחוזרת אחרי "הדרן עלך פרק…" — מבנה המחבר (הפרק נפתח באמצע דף) — נשארת.

## מה תוקן, ביחס לקבצים שהומרו מראש

| בעיה | תיקון |
| --- | --- |
| BOM + CRLF בכל הקבצים | UTF-8 בלי BOM, LF |

| שורת כריכה "בס"ד …" של כל קובץ־חלק נשארה באמצע הספר (1–10 בכל מסכת, בכמה צורות) | נמחקה |
| כותרות דף כפולות בחיבורי קבצים | נמחקו |
| `Conection Type: commentary` ושמות "… הערות" | `footnotes` ו־`הערות על <שם הבסיס>` — בלי זה ההערות נשארות ספר נפרד ולא נפתחות מהסמן |
| `<i>` בהערות (2–27 הערות ב־11 מסכתות) | `<em>` — ה־`<i>` פוסל את המיזוג של כל המסכת |

| כותרות דף בלי נקודה/נקודתיים ("דף יז", וגם "7") — 8 מקרים | הצד נגזר מכותרת הדף התקינה הבאה (`דף יז` + `דף יז:` ← `דף יז.`) |

הרצף של כותרות הדפים נבדק מול אורך המסכת. אלה החורים שבקבצי ה־Word עצמם (הם מצוינים גם בתיאור הספר):

| מסכת | חסר |
| --- | --- |
| כריתות | הכרך מסתיים בדף כד עמוד ב; דפים כה–כח (סוף המסכת) חסרים — כך גם בשם הקובץ ("חסר סוף המסכת") |
| יבמות | דפים קז–קח |
| פסחים | דפים עז–צא ועמוד א של דף צב |
| נדרים | עמוד א של דף סד |
| סוכה | עמוד ב של דף י |
| תמורה | דף ה ועמוד א של דף ו (כך גם בשם הקובץ: "חסר דף ה") |

כותרת "דף כב." מופיעה פעמיים בבבא בתרא (שני חלקים שונים של הדף, בלי גבול פרק ביניהם) — כך במקור.

## הערות למי שיחזור לכאן

- **בכורות** אין לו docx. הוא עובר את אותו צינור (`ConvertedTxt`) מהקובץ שהומר מראש, ולכן אי אפשר לאמת אותו
  מול המקור; הוא נבדק מול הקובץ שהתקבל בלבד (`verify_conversion.py`, ההבדל היחיד: "דף מו" ← "דף מו.").
- `manual_links_lineage.json` (`source_links_tree_sha256`, `packaged_links_tree_sha256`) מחושב על כל קובצי ה־links בעץ,
  ולכן נכתב בקומיט שמוסיף אותם. הערך שבעץ הועבר לעץ שמכיל את 15 קובצי ה־links האלה בלבד; הוספת links אחרים
  באותו קומיט — לחשב מחדש (`manual_links_packaging.tree_hashes`, ואז `canonical_bytes(...) + b"\n"`).
- **זכויות:** בעמוד הפתיחה של הספר מודפס "כל הזכויות שמורות. אין לעשות שימוש מסחרי בכל צורה שהוא בספר או
  בחלקו". ההפצה כאן מחייבת אישור מהמחבר (shalmeicohen@gmail.com לפי השער); ר' הרישיונות ב־`README.md` שבשורש.
- ה־PDF של המחבר זמינים באתר daf-yomi (`files.daf-yomi.com/files/klali/sfarim/shalmey-kohen-<מסכת>.pdf`) —
  מקור להשוואת הערות בעתיד.
